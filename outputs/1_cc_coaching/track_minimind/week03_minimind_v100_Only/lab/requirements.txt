# ---------------------------------------------------------------------------
# 两条路径的差异，以及代码怎么同时活在两边
# ---------------------------------------------------------------------------
# 1) GradScaler：torch 2.1 只有 torch.cuda.amp.GradScaler（且只服务 CUDA）；
#    2.3+ 才有 torch.amp.GradScaler(device_type)。
#    common.py 的 new_torch_scaler() 两个都试，CPU 一律走自带的 PurePythonScaler。
# 2) torch.distributed.checkpoint：2.1 的公开入口是 save_state_dict /
#    load_state_dict，2.2+ 改推 save / load。ckpt_reshard.py 两个都试。
# 3) SDPA 后端选择：2.1 用 torch.backends.cuda.sdp_kernel；2.3+ 是
#    torch.nn.attention.sdpa_kernel。common.py 的 sdpa_context() 只用 2.1 的那个，
#    检测不到时降级为 auto 并打一行警告。
# 4) bfloat16：V100(sm70) 不支持。assert_dtype_supported() 在参数解析阶段就拒绝，
#    不等到 autocast 里报错。
